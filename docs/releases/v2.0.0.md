# 拾讯 · Signal Loom v2.0.0

状态：版本准备，尚未创建 `v2.0.0` 标签或 GitHub Release。本说明汇总已经合入 `main` 的功能；合并本次文档 PR 不会自动部署服务器。

## 这一版带来什么

Signal Loom 从早期 Python/FastAPI 应用演进为 Go + React + SQLite 的单机阅读站。由于运行方式、构建工具链和部分来源类型的支持范围发生变化，本次按主要版本升级整理。

| 方面 | v2.0.0 的行为 |
| --- | --- |
| 阅读界面 | 纸张日间与夜间主题、逐字组装、植物背景与 Alfama 城市页脚；减少动态效果设置可跳过动画 |
| 图片与分享 | 图片等比完整展示；长文与多图自动分页，每页包含本站消息链接和二维码，支持 PNG 与整套 ZIP |
| 回访 | 本地收藏保存消息 ID，打开时重新检查公开权限；阅读进度通过明确的继续阅读操作恢复 |
| 多语言 | 公开界面和图文指南支持简体中文、English、日本語、Español；消息正文保持原文，管理界面使用中文 |
| 自部署 | 公开站点名称、描述与链接可通过环境变量配置；默认 Compose 独立运行 |
| 媒体缓存 | 默认 5 GiB 软上限与 30 天保留策略，提供受管理会话保护的容量统计和维护入口 |
| 发布与维护 | 制品校验、包含 WAL 的在线备份、隔离候选验证和保留当前数据库的回滚；CI 覆盖测试、构建、漏洞与敏感内容检查 |

完整功能截图见[中文指南](../../README.md)、[English](../../README.en.md)、[日本語](../../README.ja.md)、[Español](../../README.es.md)。按实现日期整理的改动见 [Changelog](../../CHANGELOG.md)。

## 升级前需要核对

1. **确认运行入口。** 当前镜像运行 `cmd/server` 构建的 Go 程序；`app/` 和 `tests/` 是历史 Python 实现。当前 Go 运行时支持 `telegram_public`，尚未接入 `telegram_bot`、Bot 长轮询或 RSS。依赖这些功能的旧部署需要先评估，不能直接假定功能等价。
2. **先备份再验证。** 使用[运维说明](../operations.md)中的 SQLite 在线备份命令保留 WAL 中已提交的数据，并保护私有配置与需要长期保存的媒体。现有制品发布工具面向已使用 Go 容器的部署；它不证明 Python v1.0.0 数据库可以直接升级，旧实例需先在隔离副本验证数据与来源配置。
3. **检查构建环境。** Go 需要 1.27.4+；前端要求 Node.js `^22.22.2 || ^24.15.0 || >=26.0.0`，使用锁文件执行 `npm ci`。前端已升级到 React 19.3、TypeScript 7、Vite 8 和 React 插件 6。正式发布工具另需 Python 3.8+。
4. **检查公开网址与管理入口。** 配置稳定的 `PUBLIC_BASE_URL` origin，让分享卡片和二维码指向自己的站点。生产通过 HTTPS 反向代理访问，设置独立管理密钥和会话密钥；默认服务绑定 `127.0.0.1:8000`。
5. **确认缓存保留需求。** 默认年龄与容量策略会回收缓存文件。首次启用年龄策略给予历史缓存一个完整保留周期的宽限，容量限制仍然生效。需要永久保存的媒体应单独归档。

项目名称与仓库已改为 `douxiaohu/signal-loom`，现有 `telegram-forwarder` 服务名、`telegram-radar` 二进制兼容名称与 `telegram_forwarder.db` 数据库名仍用于已有部署；升级时不要仅因更名就移动持久化数据。

## English release summary

Signal Loom v2.0.0 prepares the Go-based reading site with complete-image viewing, paginated text and image sharing, message URLs and QR codes, local bookmarks, reading recovery, four public UI languages, configurable branding and bounded media caching.

This is a major upgrade from the Python-based v1.0.0. The current runtime supports public Telegram channels; bot polling and RSS are not implemented in Go. Existing Python deployments need an isolated migration assessment. Build requirements are Go 1.27.4+ and Node.js `^22.22.2 || ^24.15.0 || >=26.0.0`; artifact release tooling also needs Python 3.8+.

These notes prepare a release and do not publish a tag or deploy production. Follow the [operations guide](../operations.md) for backups, artifact verification, deployment and rollback.
