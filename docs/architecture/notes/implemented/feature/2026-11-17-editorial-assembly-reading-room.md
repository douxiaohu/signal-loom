# Agent Note: 公开资讯首页的纸张阅读室与绘图动效

Status: implemented

## Problem

用户要求将 delineate Assembly 的前端效果复刻到当前公开资讯界面，并结合 Climate Garden 的植物动画、Alfama 水彩城市页脚。现有首页包含搜索、来源筛选、游标分页、媒体查看和主题持久化，绘图过程不能占用这些交互的 DOM。

历史审计：现有 `docs/architecture/` 记录覆盖后端与模块边界，没有相同的动效或主题决定；没有需要替代、归档或互链的活跃笔记。本目录沿用仓库现有的架构文档归属，笔记采用生命周期和类别子目录。

## Decision

首页采用暖白纸张、中文衬线标题、橄榄绿色控件和开放式时间线。新访客从纸张主题打开；已经保存的主题继续沿用。管理端仍使用原有主题选择器和默认值。公开首页的两处日夜按钮共享现有主题事件，Alfama 通过组件局部 `data-light` 接收同一个状态。

复用 MIT 许可的 delineate Assembly 引擎。Crew 的文本替换操作限制在 `AssemblyIntro` 的静态 HTML 小节中，React 管理的表单和消息节点不交给 Crew。`dangerouslySetInnerHTML` 的值保持对象身份稳定，动画状态通过介绍区的 class 管理，避免 React 状态重绘重新写入 HTML、使 Crew 的任务指向已移除的节点。Assembly 按需导入，等待字体完成后测量；完成后停止时钟并清理图层，重播从原始文案重新创建。

用户补充要求消息列表也逐字组装。`message-assembly.ts` 复用 Hand、Marks 和 Clock，在每张消息卡片首次进入视口时拉框、逐字显现来源、时间、标题、正文，并拉出媒体区域。它通过只读 Range 测量实际字形，逐步调整原元素的 clip-path；完整文本、链接节点、媒体实例和事件始终由 React 保有，不复制媒体、不替换文本。裁剪坐标使用当前布局计算，因此滚动不会让遮罩错位。长段落按长度加速，折叠范围以外的段落不参与动画。当前消息使用两倍时钟并优先显示媒体，单卡 3.2 秒恢复完成状态；具体修复与分享分页见[媒体修复记录](../bug-fix/2026-11-17-complete-media-and-paged-share-cards.md)。

消息的指针、选区和打字光标在独立的 aria-hidden 图层中，图层不接收输入。卡片收到点击、焦点、键盘或复制事件，以及离开视口、窗口调整大小、减少动态效果切换时，立即恢复完整显示并停止时钟；隐藏标签页时暂停。完成记录限制为 512 条，以消息 ID 和时间/内容版本区分，切换筛选或刷新同一条内容不会反复组装，新增分页和修改过正文的消息会重新进入流程。管理端不挂载消息动画。

植物与 Alfama 使用本地静态 SVG / HTML 绘图，保留原项目的日夜配色、分层和许可。它们在接近视口时加载；组件卸载时取消请求。植物分组按原绘图的生长时间展开。页脚无限动画由 24 fps 的时钟推进，离屏、隐藏标签页、八秒无输入时停止。减少动态效果时直接呈现完整首页，跳过 Assembly 脚本，静态呈现植物与页脚。

Assembly 样式限定在首页引导区和正在组装的公开消息卡片中，帧动画名带前缀。Alfama 的绘图保持 `al-` 命名空间。公开阅读配色通过 `html:has(.public-page)` 限定，不影响管理页。静态资源和源码附带上游 MIT 许可及来源说明。

## Alternatives considered

- 将整个首页交给原版 Crew：能最大化复现逐字构建效果，但它会替换叶子元素，与 React 更新消息、搜索输入和筛选状态争夺 DOM，因此只有静态介绍区使用 Crew；消息逐字效果通过字形遮罩实现。
- 使用原版页脚 iframe：隔离简单，但主页面主题、锚点和管理入口不能自然协同，还会产生嵌套滚动，因此采用本地绘图资源加 React 页脚外壳。
- 将绘图嵌入 JavaScript：少一次请求，但会让不滚动到页脚的读者也下载整幅城市。当前插画资源由 IntersectionObserver 延迟加载。
- 只调高原来单一的脚本体积上限：实现容易，但会掩盖动画是否被意外并入阅读代码。当前分别检查阅读脚本 260 KiB 和按需 Assembly 36 KiB；原阅读上限是 250 KiB，新增首页组件与动效生命周期逻辑占用额外额度。

## Consequences

首页增加一个有留白的引导区，读者通过“开始阅读”或跳转链接直达原有消息时间线。三个屏幕尺寸保留搜索、来源筛选、媒体查看、刷新和分页。公开首页的原四主题按钮简化为日夜按钮，管理端仍可选择四个已存主题。

资源代价为约 393 KiB 的城市绘图、约 100 KiB 的植物绘图和约 32 kB 的按需 Assembly 脚本，均由本站提供；城市与植物不会写入主脚本包。消息与首页共用同一个按需模块，不重复下载引擎。资源请求失败时保留文字、导航和完整阅读功能。

本次只修改前端和相关体积检查，不改 API、公开可见性或生产数据。人工预览使用独立数据库副本，副本的来源改用不参与采集的临时适配器，监听地址为 127.0.0.1；原数据库与采集配置不变。浏览器功能测试使用现有的 API fixture，不能作为生产发布或实时采集验收。

验证包括 TypeScript / Vite 生产构建、前端单元测试、1440 / 768 / 390 三尺寸的浏览器功能回归、Assembly 重播期间操作媒体筛选、消息逐字期间复制完整正文和打开媒体、新分页组装、筛选回访不重播、减少动态效果、Alfama 日夜同步，以及实际浏览器截图检查。相关命令为 `cd frontend && npm run build && npm test && npm run test:e2e`。
